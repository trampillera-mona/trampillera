# Community Code of Conduct

TRAMPILLERA aims to maintain a constructive environment for everyone who participates in project discussions and contributions.

## Expected behavior

- Be respectful, considerate, and open to different perspectives.
- Discuss technical decisions using evidence, clear reasoning, and good-faith questions.
- Give useful feedback and accept reasonable criticism.
- Respect privacy, intellectual property, licenses, and project boundaries.
- Make space for newcomers and explain context where practical.

## Unacceptable behavior

- Harassment, threats, discrimination, intimidation, or personal attacks.
- Deliberate disruption, spam, doxxing, or publishing private information without consent.
- Impersonation or knowingly misleading claims about project affiliation, endorsement, certification, or authority.
- Sharing secrets, credentials, or private operational data.

## Scope and enforcement

This standard applies to project spaces, including issues, pull requests, discussions, and other spaces when someone is representing or directly participating in the project community.

Project maintainers may remove content, close discussions, or restrict participation when necessary to protect the community. Decisions should be proportionate to the conduct and the available context.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers through the repository's available contact channels. For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of posting exploit details publicly.

This code of conduct is a community participation policy, not a substitute for applicable law or platform terms.
