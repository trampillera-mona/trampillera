# Security Policy

Security is important to TRAMPILLERA. Please report suspected vulnerabilities responsibly.

## Reporting a vulnerability

Do not publish credentials, exploit instructions, sensitive personal data, or details that would put a live deployment at risk in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository maintainer through a private contact channel listed on the project's official website or GitHub profile. Include:

- a concise description of the suspected vulnerability;
- affected versions, components, and deployment configuration;
- steps to reproduce in a safe test environment;
- potential impact and any suggested mitigation.

Do not send real user data, production database dumps, passwords, or API keys.

## What to expect

The maintainer will make a reasonable effort to acknowledge a report, assess its impact, and coordinate a fix or mitigation. Response and remediation times are not guaranteed.

Please allow time for investigation and a coordinated fix before public disclosure. Good-faith security research should avoid privacy violations, service disruption, data destruction, and access to systems or data beyond what is necessary to demonstrate the issue.

## Deployment responsibility

Self-hosters are responsible for their own secrets, infrastructure, backups, access controls, updates, and compliance obligations. The repository's documentation is not a security certification or a guarantee that a particular deployment is secure.
